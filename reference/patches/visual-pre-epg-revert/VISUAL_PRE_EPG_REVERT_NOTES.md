# Optimus — painel visual restaurado

Esta build retorna ao painel de canais da versão anterior às alterações de EPG inferior, quadro reduzido e fonte ampliada. O vídeo permanece ao fundo e o layout original do overlay é preservado.

Foi mantida somente a correção de host Xtream/M3U para evitar que URLs `get.php` ou `player_api.php` salvas sejam usadas como base incorreta do catálogo.
