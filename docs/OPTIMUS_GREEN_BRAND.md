# Optimus verde metálico

Esta versão substitui a identidade visual dourada do Optimus pelo logo verde metálico fornecido pelo proprietário do projeto.

O emblema verde sem wordmark é usado no ícone normal, no ícone redondo e no `BrandMark` do topo do sidebar. O logo completo verde é usado no splash e no banner da Android TV/TV Box. As variantes de densidade `mdpi`, `hdpi`, `xhdpi`, `xxhdpi` e `xxxhdpi` foram geradas para os recursos do launcher.

O nome visível do aplicativo continua sendo `Optimus`. O `applicationId` técnico permanece `com.iptv.newvision` para preservar a instalação, as preferências, as classes de autenticação e o fluxo MAC/Rencia.

A build mantém EPG esportivo, cores persistentes, validade do painel, Perfil, Listas, failover, navegação direta das marcas para Séries, avatares otimizados e demais recursos existentes.
