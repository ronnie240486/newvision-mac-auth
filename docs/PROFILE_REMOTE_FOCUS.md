# Perfis com controle remoto

A tela `Quem está assistindo?` foi ajustada para TV Box. Os cards de perfil e os avatares do cadastro são focáveis, o D-pad esquerdo/direito percorre horizontalmente a faixa, e o OK confirma o item focado. O primeiro item recebe foco inicial.

O avatar selecionado permanece com borda/tarja dourada e escala levemente maior; o item apenas focado recebe uma borda mais forte. O foco pode descer para o campo de nome e seguir para `SALVAR E ENTRAR`, permitindo concluir o cadastro sem touchscreen.

O enquadramento dos avatares usa `FIT_CENTER` para evitar cortes de cabeça. O aquecimento assíncrono do catálogo durante a tela de perfis permanece habilitado.
