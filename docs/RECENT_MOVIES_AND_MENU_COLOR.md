# Filmes recentes, cor do menu e botão Perfil

A Home agora deduplica filmes antes da ordenação de “Top Filmes Recém Adicionados” usando ID e, quando necessário, título/capa/URL normalizados.

A tela de configurações recebeu “Escolher cor do menu”, com 50 cores persistidas localmente e aplicadas ao menu, foco e destaques.

O menu lateral recebeu “Perfil” acima de “Configurações”, abrindo o seletor de perfis a qualquer momento sem criar uma nova sessão Xtream.
